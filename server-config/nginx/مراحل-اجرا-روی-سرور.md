# مراحل دقیق روی سرور (برای رفع CORS)

همهٔ دستورات را **روی سرور** و با کاربری که به `sudo` دسترسی دارد اجرا کنید.

---

## مرحله ۱ — بکاپ از فایل‌های فعلی

```bash
sudo cp /etc/nginx/sites-available/manehaghighi /etc/nginx/sites-available/manehaghighi.bak
sudo cp /etc/nginx/sites-available/api.manehaghighi.com /etc/nginx/sites-available/api.manehaghighi.com.bak
```

---

## مرحله ۲ — کپی کردن فایل map به nginx

فایل `cors-api.map.conf` را از پروژه به سرور برده و در مسیر nginx بگذارید. اگر پروژه روی سرور است:

```bash
sudo cp /path/to/new-haghighi/server-config/nginx/cors-api.map.conf /etc/nginx/
```

اگر از کامپیوتر خودتان آپلود می‌کنید، اول فایل را با scp/rsync به سرور ببرید، بعد همان دستور `cp` را با مسیر درست روی سرور بزنید.

---

## مرحله ۳ — اضافه کردن include در nginx.conf

```bash
sudo nano /etc/nginx/nginx.conf
```

بالای فایل یک بلوک شبیه این دارید:

```nginx
http {
    ...
    include /etc/nginx/sites-enabled/*;
}
```

**داخل** بلوک `http { ... }` و **قبل از** خط `include /etc/nginx/sites-enabled/*;` این خط را اضافه کنید:

```nginx
    include /etc/nginx/cors-api.map.conf;
```

مثال درست:

```nginx
http {
    ...
    include /etc/nginx/cors-api.map.conf;
    include /etc/nginx/sites-enabled/*;
}
```

ذخیره کنید (در nano: Ctrl+O، Enter، بعد Ctrl+X).

---

## مرحله ۴ — جایگزین کردن فایل manehaghighi

محتوای فایل **manehaghighi** را با محتوای **manehaghighi.sites.conf** عوض کنید.

**روش الف — با nano:**  
فایل پروژه `manehaghighi.sites.conf` را باز کنید، همه را کپی کنید. روی سرور:

```bash
sudo nano /etc/nginx/sites-available/manehaghighi
```

همهٔ محتوا را پاک کنید و محتوای `manehaghighi.sites.conf` را paste کنید. ذخیره و خروج.

**روش ب — با scp از لپ‌تاپ:**  
از لپ‌تاپ (پوشهٔ پروژه):

```bash
scp server-config/nginx/manehaghighi.sites.conf user@YOUR_SERVER_IP:/tmp/
```

روی سرور:

```bash
sudo cp /tmp/manehaghighi.sites.conf /etc/nginx/sites-available/manehaghighi
```

---

## مرحله ۵ — جایگزین کردن فایل api.manehaghighi.com

محتوای فایل **api.manehaghighi.com** را با محتوای **api.manehaghighi.com.server.conf** عوض کنید.

**روش الف — با nano:**  
محتوای `api.manehaghighi.com.server.conf` را کپی کنید. روی سرور:

```bash
sudo nano /etc/nginx/sites-available/api.manehaghighi.com
```

همه را پاک کنید و محتوای جدید را paste کنید. ذخیره و خروج.

**روش ب — با scp:**  
از لپ‌تاپ:

```bash
scp server-config/nginx/api.manehaghighi.com.server.conf user@YOUR_SERVER_IP:/tmp/
```

روی سرور:

```bash
sudo cp /tmp/api.manehaghighi.com.server.conf /etc/nginx/sites-available/api.manehaghighi.com
```

---

## مرحله ۶ — مطمئن شدن از لینک در sites-enabled

```bash
ls -la /etc/nginx/sites-enabled/
```

باید هر دو را ببینید (یا حداقل لینک به آن‌ها):

- `manehaghighi` یا `../sites-available/manehaghighi`
- `api.manehaghighi.com` یا `../sites-available/api.manehaghighi.com`

اگر **api.manehaghighi.com** در لیست نبود:

```bash
sudo ln -s /etc/nginx/sites-available/api.manehaghighi.com /etc/nginx/sites-enabled/
```

اگر **manehaghighi** نبود:

```bash
sudo ln -s /etc/nginx/sites-available/manehaghighi /etc/nginx/sites-enabled/
```

---

## مرحله ۷ — تست و ریلود nginx

```bash
sudo nginx -t
```

اگر پیام `syntax is ok` و `test is successful` آمد:

```bash
sudo systemctl reload nginx
```

اگر `nginx -t` خطا داد، خروجی خطا را بفرست تا همان را اصلاح کنیم.

---

## مرحله ۸ — تست در مرورگر

1. از **admin.manehaghighi.com** لاگین کنید؛ نباید CORS ببینید.
2. از **manehaghighi.com** (یا www) اگر به API درخواست می‌زنید، آن را هم تست کنید؛ نباید CORS ببینید.

اگر هنوز CORS دیدید، در تب Network (F12) روی درخواست به api.manehaghighi.com کلیک کنید و ببینید در Response Headers آیا `Access-Control-Allow-Origin` هست یا نه؛ همان را بفرست.

| مرحله | کار |
|-------|-----|
| ۱ | بکاپ از manehaghighi و api.manehaghighi.com |

| ۳ | در nginx.conf داخل http {} اضافه کردن: include /etc/nginx/cors-api.map.conf; |

| ۵ | جایگزین کردن محتوای api.manehaghighi.com با api.manehaghighi.com.server.conf |
| ۶ | چک کردن لینک در sites-enabled |
