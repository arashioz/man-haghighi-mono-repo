## 🎬 مدیریت ویدیو پادکست‌ها

این به‌روزرسانی یک موجودیت و بخش مدیریتی جدید برای «ویدیو پادکست‌ها» اضافه می‌کند.

### 🗄️ تغییرات پایگاه داده

یک مدل جدید با نام `VideoPodcast` به `schema.prisma` اضافه شده است. برای اعمال تغییرات:

```bash
cd /Users/arash/Desktop/new-haghighi/backend
npx prisma migrate dev --name create_video_podcasts
# یا در محیط تولید
npx prisma migrate deploy
```

بعد از اعمال مایگریشن، Prisma Client را به‌روزرسانی کنید:

```bash
npx prisma generate
```

### 🔌 API جدید

Endpointهای جدید تحت مسیر `/api/video-podcasts` در دسترس هستند:

- `GET /video-podcasts` — فهرست همه ویدیو پادکست‌ها
- `GET /video-podcasts/published` — فقط موارد منتشر شده
- `GET /video-podcasts/:id` — جزئیات یک مورد
- `GET /video-podcasts/:id/stream` — پخش ویدیو با پشتیبانی Range
- `POST /video-podcasts` — ایجاد (فقط ادمین، `multipart/form-data` با فیلد `video`)
- `PATCH /video-podcasts/:id` — ویرایش (فقط ادمین، `multipart/form-data`)
- `DELETE /video-podcasts/:id` — حذف (فقط ادمین)

**نکته:** در صورت ارسال فایل، فیلد فایل باید `video` باشد. می‌توانید به جای فایل، لینک خارجی ویدیو را در فیلد `videoFile` قرار دهید.

### 🖥️ پنل ادمین

- منوی جدید «ویدیو پادکست‌ها» در سایدبار اضافه شده است.
- امکان ایجاد، ویرایش، حذف، آپلود فایل ویدیو یا ثبت لینک خارجی فراهم است.
- پیش‌نمایش ویدیو، وضعیت انتشار، مدت زمان و تاریخ ایجاد در جدول نمایش داده می‌شود.
- فرم‌ها از `datetime-local` برای کنترل تاریخ انتشار استفاده می‌کنند و به‌صورت خودکار به ISO تبدیل می‌شود.

### 📊 داشبورد

- کارت آماری جدیدی به داشبورد ادمین اضافه شده است که تعداد کل ویدیو پادکست‌ها را نمایش می‌دهد.

### ✅ کارهای بعدی

- در صورت نیاز به تصویر بندانگشتی، فعلاً لینک وارد کنید یا ابتدا فایل را در بخش «آپلودها» بارگذاری و لینک آن را قرار دهید.
- برای مصرف در وب‌سایت اصلی، از endpoint‌های جدید استفاده کنید (`GET /video-podcasts/published` یا `GET /video-podcasts/:id/stream`).
