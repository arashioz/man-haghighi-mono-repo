# بازنشانی سیستم فروش

این اسکریپت تمام داده‌های مربوط به سیستم فروش را پاک می‌کند تا بتوانید تیم‌های فروش را از ابتدا بسازید.

## چه داده‌هایی پاک می‌شوند:

- ✅ تمام لینک‌های پرداخت (`payment_links`)
- ✅ تمام اعضای تیم فروش (غیرفعال می‌شوند) (`sales_team_members`)
- ✅ تمام تیم‌های فروش (`sales_teams`)
- ✅ تمام فاکتورها (`invoices`)
- ✅ تمام تراکنش‌ها (`transactions`)

## نحوه استفاده:

### روش 1: اجرای مستقیم اسکریپت TypeScript
```bash
cd backend
npx ts-node scripts/reset-sales-system.ts
```

### روش 2: اجرای اسکریپت Shell (توصیه می‌شود)
```bash
cd backend
./scripts/reset-sales-system.sh
```

## اخطارها:

- ⚠️ **این عملیات قابل بازگشت نیست!**
- ⚠️ تمام داده‌های فروش پاک خواهند شد
- ⚠️ قبل از اجرای اسکریپت از داده‌های مهم پشتیبان بگیرید

## بعد از اجرای اسکریپت:

1. پنل ادمین را باز کنید
2. به بخش "فروشندگان" بروید
3. تیم‌های فروش را از ابتدا بسازید
4. فروشندگان را به تیم‌ها اضافه کنید
5. لینک‌های پرداخت را دوباره ایجاد کنید
