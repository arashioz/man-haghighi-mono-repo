# اپ موبایل من حقیقی (Expo)

اپ React Native با Expo برای کاربران عادی: ورود و مشاهده لیست دوره‌های خریداری‌شده و پخش ویدیو/صوتی هر دوره.

## پیش‌نیاز

- Node.js 18+
- npm یا yarn
- Expo Go روی گوشی (برای تست) یا اندروید استودیو / Xcode برای شبیه‌ساز

## نصب و اجرا

```bash
cd mobile
npm install
npx expo start
```

سپس QR کد را با اپ **Expo Go** اسکن کنید (همان شبکه وای‌فای).

برای اندروید: `npx expo start --android`  
برای iOS: `npx expo start --ios`

## آدرس API (بکند اصلی)

اپ به **بکند اصلی پروداکشن** وصل است: `https://api.manehaghighi.com/api`  
(ورود با همان user/pass دیتابیس اصلی، بدون OTP.)

آدرس از `app.json` → `extra.apiUrl` خوانده می‌شود؛ برای تست محلی همان مقدار را در `app.json` عوض کنید و از IP ماشین استفاده کنید (نه localhost).

## قابلیت‌ها

1. **صفحه لاگین**: ورود با شماره موبایل یا ایمیل + رمز عبور (همان API بکند).
2. **دوره‌های من**: بعد از ورود فقط دوره‌های ثبت‌نام‌شده کاربر از API `GET /courses/my-courses` نمایش داده می‌شود.
3. **جزئیات دوره**: با زدن روی هر دوره، لیست ویدیوها و فایل‌های صوتی آن دوره دیده می‌شود.
4. **پخش ویدیو**: با زدن روی هر ویدیو، لینک استریم با توکن از API گرفته شده و در یک مودال تمام‌صفحه با `expo-av` پخش می‌شود.
5. **پخش صوتی**: با زدن روی هر آیتم صوتی، استریم صوتی با `expo-av` پخش می‌شود و با دکمه توقف/پخش و بستن قابل کنترل است.

## ساختار

- `src/api/`: کلاینت axios، auth و courses (همه از API بکند).
- `src/context/AuthContext.tsx`: وضعیت لاگین و توکن (ذخیره در AsyncStorage).
- `src/screens/`: Login، لیست دوره‌ها، جزئیات دوره (لیست ویدیو/صوت + پخش).
- `src/navigation/RootNavigator.tsx`: اگر کاربر لاگین نبود فقط Login، وگرنه لیست دوره‌ها و صفحه جزئیات دوره.

## سازگاری با Expo Go (iOS / Android)

این پروژه با **Expo SDK 52** ساخته شده. برای اجرا روی گوشی حتماً نسخه‌ی Expo Go را با SDK 52 هماهنگ کنید:
- اگر در Expo Go پیام «Project is incompatible» دیدید (مثلاً Expo Go برای SDK 54 است)، یا **Expo Go را به نسخه‌ای که SDK 52 را پشتیبانی می‌کند بروز کنید**، یا پروژه را به SDK 54 ارتقا دهید: `npx expo install expo@54` و سپس `npx expo install --fix`.

## آیکون و اسپلش

در `app.json` مسیر آیکون/اسپلش حذف شده تا بدون فایل در `assets` هم اجرا شود. در صورت نیاز می‌توانید `icon` و `splash.image` را دوباره تنظیم کنید و فایل‌ها را در پوشه `assets` قرار دهید.
